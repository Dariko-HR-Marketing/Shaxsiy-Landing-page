# 🚀 Render.com Platformasida Saytni Bepul va Qulay Ishga Tushirish (Deploy)

[Render.com](https://render.com/) — static saytlar va web-ilovalarni bepul, juda tez va 100% ishonchli joylashtirish uchun eng yaxshi platformalardan biri!

---

## ⚡️ Render.com da 1 Daqiqada Ishga Tushirish Bosqichlari:

1. **[dashboard.render.com](https://dashboard.render.com/) saytiga kiring:**
   - O'z akkauntingizga kiring (GitHub yoki Email orqali).

2. **Yangi Static Site Yaratish:**
   - Ekranning yuqori o'ng burchagidagi **"New +"** tugmasini bosing va **"Static Site"** ni tanlang.

3. **Loyiha Manzilini Ko'rsatish:**
   - GitHub repository'ingizni tanlang (yoki ulrang).
   - **Publish Directory:** `DARIKO_v14_FINAL/dariko_v14/public_html` (yoki `public_html`).
   - **Build Command:** Bo'sh qoldiring (static HTML/JS foydalanilgan).

4. **"Create Static Site" tugmasini bosing:**
   - Atigi **15-20 soniyada** Render saytingizni ishga tushiradi va bepul `dariko-v14-final.onrender.com` havolasini taqdim etadi!

---

## 🌐 Shaxsiy Domen (`Dariko.uz`) Ulash:
Render Dashboard -> Loyihangiz -> **Settings** -> **Custom Domains** bo'limida `dariko.uz` ni kiritib, DNS sozlamalariga CNAME va A Record ni kiritsangiz, **bepul SSL sertifikati** avtomatik ishga tushadi!
